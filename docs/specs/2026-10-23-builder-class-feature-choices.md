# Native class feature choices

The disposable profile installs `character-builder-class-feature-choices.sql` after the steps, catalog, progression, race-score repair, Expertise and multiclass companions. The subsequent Favored Enemy companion composes its normalizer with this stage. Hosted installation and Vercel changes remain outside this local work.

The importer reads the genuine cached 2014 API sources. New imports publish genuine immutable snapshots; existing pinned narrative-only versions are not rewritten. Bard Expertise at levels 3 and 10 uses eighteen skill proficiencies and the existing native eligibility validator. Ranger Natural Explorer at levels 1, 6 and 10 earns one distinct additional terrain per source. Favored Enemy retains its atomic type-or-two-humanoids contract as source metadata, rather than unconditional choices for mutually exclusive branches.

Generic child feature choices include Sorcerer Metamagic at 3/10/17, Warlock Pact Boon, Hunter options, Draconic Ancestry and Circle of the Land. Each accepted selection resolves an accessible immutable child from the exact parent source's finite manifest. The graph stores a real child content pin with reserved source provenance. Retained pins preserve their IDs and versions; changing or losing the parent removes only its derived pins. These selections expose the actual child descriptions and their modeled mechanics; this does not imply every described combat action is automated.

Invocation selection uses the 32 source references. The immutable Warlock table determines the allowance for the selected Warlock level, independently of total character level. Typed child requirements enforce class level, actual known spell rows and actual accepted Pact child pins. Changing spells, pact or level prunes only options that stopped qualifying. A submitted invalid invocation fails atomically. Beguiling Influence contributes its actual Deception/Persuasion proficiency grants through the selected child pin.

Additional Fighting Style uses the new planned subclass feature manifests. The command accepts the exact class or subclass owning controller and earned level. All styles are rebuilt after subclass manifests are compiled, and the same logical style name cannot be chosen twice, including through different class sources. Existing style pin context and IDs are preserved.

The private helper requires the current same-transaction builder capability and lock context. It changes only the compiler's pending choices and graph. Existing finalizers, revisions, receipts, history constraints and original/secondary class roles remain responsible for applying and accepting that graph. New helpers are private and owner-only. The installer checks exact planner preimages and postimages, preserves each original routine's owner, ACL and attributes, and verifies all thirteen writer gates and class/hit-die gates remain closed.
