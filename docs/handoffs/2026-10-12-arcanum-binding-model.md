This child produces advisory payment intent; it does not enable advanced casts or select/save a spell.

`advanced-descriptor.ts` parses known feature data through the existing immutable snapshot parser, then strict/no-default descriptor evidence from the **same original raw feature envelope**. Parsed-only or separately supplied descriptors cannot certify eligibility. Exact one long-rest feature use and declared list/spell/base cast level are required; second bonus/free/fixed casting policies are unsupported by this bounded adapter.

`advanced-binding.ts` checks modeled controller/captured-grant/derived-ref equality, current exact selected parent/subclass graph, earliest explicit numbered feature unlock equal to declared feature gain level, class-level activation, source list/finite shared casting math, raw contributors before generic resource slug deduplication, and valid unused state before considering selection absent. It rejects malformed/exhausted present usage, inherited/accessor usage and resource collisions. A declared binding must match current class/controller/grant/feature pins and one exact eligible spell snapshot. Output is ready/unselected/unavailable with existing feature resource payment intent and immutable spell/profile; no statePatch, save, roll or catalog lookup.

Fixtures are originally authored `homebrew`/`personal` immutable envelopes with valid UUIDs/timestamps. The Pact level5 pool and separate declared level6–9 feature tiers prove payment-intent independence from normal learning/upcast capacity. Captured-grant and readable-ref records are **modeled server evidence**, not live provenance, grant activation, permissions, database freshness, receipts or copy proof. Other-author historical shared pins are modeled readable inputs; the model does not grant access.

The current production read DTO strips unknown descriptor data and omits feature_grant_id. This model intentionally requires original raw evidence and modeled exact edges instead of manufacturing them from those DTOs. A separately reviewed read/save/dependency/receipt contract remains necessary before production advanced casting. R09 and hosted authority/copy acceptance remain open. Existing generic resource/rest and Arcane Recovery paths remain unchanged.
