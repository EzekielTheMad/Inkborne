## Frozen proposal for the first child

1. Add a dedicated optional, **no-default** Arcanum descriptor validator and plain model types in new pure files; do not yet attach it to production feature parsing or change existing shared bonus validators. Declared descriptor: kind `arcanum`, list class, spell level6–9, selection count exactly1, permitted cast level equal spell level. Required feature class/gain level, usages exactly1 and long-rest recovery come from its validated pinned feature payload. Do not duplicate unlock tables or accept arbitrary free-cast flags. Missing/partial/legacy descriptors are explicitly unsupported/unavailable; they do not suppress ordinary sheet/rest/resource behavior.
2. Define an in-memory proposed binding with character/system, selected parent class identity, controller ref+content/version, feature grant identity+feature content/version, and selected spell content/version. A spell pin is independent from an ordinary acquisition row: Arcanum need not become a normal known/prepared/book spell. Do not persist this shape in `resolved_choices`, invent an acquisition source enum, or change uniqueness/grant overlays in this child.
3. Pure resolver consumes canonical immutable snapshots, a validated selected class/subclass source graph, an explicit captured active-grant proof DTO and a selected readable spell pin. It checks unique class/feature/controller/spell identities, same character/system, parent pairing and class-level eligibility, exact manifest edge/version, declared list/level, valid shared casting math and one matching existing resource slug. Resource slug must be that pinned feature slug; reject collisions/duplicates. Readable foreign-author shared/campaign pins remain allowed. No current-catalog lookup, total-level unlock or caller label repair.
4. Return explicit `unselected`, `ready`, or `unavailable` with reason. Ready includes exact source profile/base cast level and payment intent `{resourceSlug, maxUses:1, recovery:'long', usesToSpend:1}`. A resource-only legacy feature cannot produce ready. Validate spent state as a finite nonnegative integer; exhausted means unavailable payment, never clamp malformed state into a free use. Keep independently unlocked tiers independent. No state patch, provider call, roll or CastChoice union change yet.
5. Store nothing and create no second usage counter. Future approved execution must compose the existing slug-keyed feature_uses increment with effects/concentration in one confirmed conditional patch and use existing rest resets. [rest/helpers.ts](../../lib/rest/helpers.ts:40) already resets short resources on short rests and all resources on long rests. Shipped Arcane Recovery and explicit homebrew class scaling remain untouched.

**Owned implementation scope after challenge:** new `lib/spells/advanced-binding.ts` / descriptor validator; original canonical fixtures and focused pure tests; one handoff. No provider/page/UI/RPC/schema migration in this first child. Pure model fixtures must label the active-grant proof as modeled server data; they do not establish a live read adapter or authority.
